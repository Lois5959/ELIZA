## La Cible (Targets) :  

1. Le "Business Man" : 
Vient à Lille pour le travail, loge à Euralille, a peu de temps et ne connaît pas la ville. Il veut se programmer des activités rapidement. 

2. Le "Fan de Stade" : 
Vient pour un match au Stade Pierre Mauroy. Il cherche une activité "sport-plaisir" le lendemain matin avant de reprendre son train. 

3. Le "Local" : 
Habite Lille mais manque de motivation quand il pleut. Il utilise le bot pour trouver une alternative (salle, squash) instantanément. 

## La "Value Chain" : Comment l'information circule et crée de la valeur
# Besoin Utilisateur
- Simplicité : Ne pas chercher sur 3 sites différents.
- Fiabilité : Ne pas arriver devant un parc fermé ou sous une averse.
- Récompense : Se sentir privilégié.

# Besoin Partenaire
- Visibilité : Attirer des clients qui ne les connaissent pas.
- Remplissage: Occuper les créneaux vides (ex: heures creuses en salle).
- Conversion : Transformer un curieux en client payant.

# Solution du Chatbot
- Centralisation des infos (Météo + Lieu).
- Recommandation dynamique "Temps Réel".
- Envoi d'un Code Promo exclusif.


## KPIs (Indicateurs de Succès): 

# Le Taux de Clic (CTR) sur les Codes Promos (Retour sur Investissement) numéro 1. 
Cela prouve que le chatbot n'est pas juste un outil de discussion, mais un apporteur d'affaires. 

- Le calcul : CTR  = ( Nombre de clics sur la promo / Nombre de recommandations faites) * 100. 
Application à Lille : "Sur 100 personnes ayant cherché un lieu partenaire, 25 ont utilisé sur le code promo." 

 
# Le Temps Moyen Économisé c'est l'argument Expérience Utilisateur (UX). 
Cela justifie pourquoi le bot est meilleur que Google. Google donne des liens, le bot donne une décision. 
Une recherche manuelle (Météo + Lieu + Site du partenaire) prend environ 3 à 5 minutes, alors que le bot traite la demande en moins de 10 secondes.
